# Pulso 2.4.0

Primera edición preparada para distribuir en GitHub.

- Instalador para Windows 10/11 x64, con accesos al escritorio y al menú Inicio.
- Opción para solicitar anclaje a la barra de tareas desde la guía de Pulso; instrucciones manuales cuando Windows no permite solicitarlo.
- Interfaz e instalador en español, inglés, portugués brasileño, chino simplificado y ucraniano.
- Ajustes USB con HIDUSBF NoPatch, copias de recuperación y probador de controles.
- Paquete completo con el instalador oficial offline de .NET Framework 4.8.

Archivos de distribución: `Pulso-Setup-2.4.0-x64.exe`, `Pulso-Completo-Windows-x64.zip` y `SHA256SUMS.txt`.

La frecuencia depende del hardware. El probador funciona sin HIDUSBF. La instalación del controlador desde cero en otro equipo aún requiere una prueba real. Pulso y su instalador no tienen firma digital propia.
